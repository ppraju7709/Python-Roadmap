# 🧮 Smart Calculator

## 📖 Overview

The **Smart Calculator** is a beginner-friendly Python project developed as part of the **Python Roadmap**. It performs basic arithmetic operations through a simple menu-driven interface while handling invalid inputs and division-by-zero errors.

This project helps beginners understand Python fundamentals such as variables, functions, conditional statements, loops, and exception handling.

---

## 🎯 Objectives

- Learn Python basics through a practical project.
- Understand user input and output.
- Practice conditional statements and loops.
- Learn function creation and code organization.
- Handle invalid user input using exception handling.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ⚠️ Invalid input handling
- 🚫 Division by zero protection
- 🔁 Menu-driven interface
